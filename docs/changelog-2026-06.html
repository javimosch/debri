Changelog

June 2026

🚀

Initial Release

Fresh devin session invoker with streaming JSONL output. Creates a new tmux session for each prompt execution, avoiding session-reuse slowdowns. Supports SWE-1.6, Kimi K2.6, and other devin-supported models.

⚡

Streaming JSONL

Emit structured events for monitoring: init, chunk, done, error. Perfect for CI/CD pipelines and automated workflows.

🔧

TUI Chrome Stripping

Automatically strips devin TUI chrome (braille logo, status bars, thinking indicators) to return clean output.

📦

Single Binary

Statically compiled Go binary with no runtime dependencies. Easy to install and deploy anywhere.
