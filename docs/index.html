What You Get

Creates a new devin tmux session for each prompt execution. Avoids session-reuse slowdowns. Session is cleaned up after execution.

debri "prompt"

Single Binary

Architecture

How debri works under the hood.

1

Create tmux session

Creates a fresh devin tmux session with unique name: devin-debri-

2

Write prompt file

Writes prompt to /.devin/debri-prompt-.txt to avoid workspace trust prompts

3

Invoke devin

Runs devin -p --permission-mode dangerous --prompt-file in the tmux session

4

Poll pane

Polls tmux pane every 250ms using watermark approach to emit new output chunks

5

Clean output

Strips devin TUI chrome (braille logo, status bars, thinking indicators)

6

Cleanup

Kills tmux session and removes prompt file after execution

Installation

Get started in seconds.

Quick Install (curl)

curl -fsSL https://github.com/javimosch/debri/releases/download/v1.0.0/debri -o /usr/local/bin/debri && chmod +x /usr/local/bin/debri

Build from source

git clone https://github.com/javimosch/debri.git && cd debri && go build -o debri . && sudo mv debri /usr/local/bin/
